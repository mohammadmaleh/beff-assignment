You're joining a B2B SaaS startup (e.g B-eff.com) providing a solution for a greener society.

The product is in its pre-launch phase. Your task is to build the public landing and early user onboarding experience, along with a user dashboard, including a profile page with GDPR or similar user compliant features.

## 🎯 Objectives

Design and implement a responsive landing page, dashboard, profile, and user onboarding experience page to support early user acquisition.

## Part 1: Frontend Implementation

Using React (with TypeScript) and Tailwind CSS, implement the frontend based on your Figma designs:

- Build a responsive landing page
- Develop the full onboarding experience [Registration/Login]
- A responsive User Dashboard (either mocked data or API for user stats)
- A user profile page with any two GDPR or similar compliant features [You can use mocked data here if you like]

Ensure the frontend is cleanly structured, responsive, and accessible.

## Part 2: Backend

Create a minimal backend to support user's onboarding and offboarding:

- Implement APIs for the user onboarding experience
- Include basic server-side data validation

Use either the NestJS or FastAPI framework, keeping the backend simple and functional.

## Deliverables

1. **Source Code (Frontend + Backend)**
   a. Host on GitHub and ensure proper project structure and README

2. **Brief Documentation** (in the README or separate doc):
   a. Explanation of your design choices
   b. How you approached UI/UX intuitiveness

3. **Figma Link (Bonus)**
   a. Include your prototype and a short rationale for your design decisions
